## 生成项目结构的Python函数
```python
def generate_project_structure(root_dir='.', max_depth=3):
    """
    生成项目结构图
    
    Args:
        root_dir: 根目录路径
        max_depth: 最大深度
    
    Returns:
        项目结构字符串
    """
    import os
    from pathlib import Path
    
    ignore_patterns = {
        '.git', 'node_modules', '__pycache__', '.venv', 'venv',
        'dist', 'build', '.next', '.nuxt', '.svelte-kit',
        'target', '.idea', '.vscode', '.DS_Store'
    }
    
    def scan_dir(path, prefix='', depth=0):
        if depth > max_depth:
            return []
        
        lines = []
        try:
            items = sorted(os.listdir(path))
        except PermissionError:
            return lines
        
        # 过滤忽略的目录
        items = [item for item in items if item not in ignore_patterns]
        
        for i, item in enumerate(items):
            item_path = os.path.join(path, item)
            is_last = (i == len(items) - 1)
            
            # 当前层级的符号
            if depth == 0:
                line_prefix = ''
            else:
                line_prefix = prefix + ('└── ' if is_last else '├── ')
            
            # 如果是目录
            if os.path.isdir(item_path):
                lines.append(f'{line_prefix}{item}/')
                new_prefix = prefix + ('    ' if is_last else '│   ')
                lines.extend(scan_dir(item_path, new_prefix, depth + 1))
            else:
                # 文件
                lines.append(f'{line_prefix}{item}')
        
        return lines
    
    structure_lines = [f'{root_dir}/']
    structure_lines.extend(scan_dir(root_dir))
    
    return '\n'.join(structure_lines)

# 使用示例
if __name__ == '__main__':
    structure = generate_project_structure('.', max_depth=3)
    print(structure)
```

## 生成项目结构的Bash脚本
```bash
#!/bin/bash
# generate_structure.sh - 生成项目结构图

set -e

# 配置
MAX_DEPTH=${1:-3}
IGNORE_PATTERNS=".git|node_modules|__pycache__|.venv|venv|dist|build|.next|.nuxt|.svelte-kit|target|.idea|.vscode|.DS_Store"
OUTPUT_FILE=${2:-"PROJECT_STRUCTURE.txt"}

# 生成结构
echo "生成项目结构图..."
echo "最大深度: $MAX_DEPTH"
echo "输出文件: $OUTPUT_FILE"

# 使用tree命令（如果可用）
if command -v tree &> /dev/null; then
    echo "使用tree命令生成结构图..."
    tree -I "$IGNORE_PATTERNS" -L "$MAX_DEPTH" --dirsfirst > "$OUTPUT_FILE"
    echo "✅ 结构图已生成: $OUTPUT_FILE"
else
    echo "⚠️  tree命令未安装，使用自定义脚本..."
    
    # 自定义生成函数
    generate_structure() {
        local dir=$1
        local prefix=$2
        local depth=$3
        
        if [ $depth -gt $MAX_DEPTH ]; then
            return
        fi
        
        local items=()
        if [ -d "$dir" ]; then
            # 读取目录内容，排除忽略项
            while IFS= read -r item; do
                items+=("$item")
            done < <(ls -A "$dir" | grep -vE "$IGNORE_PATTERNS")
        fi
        
        local count=${#items[@]}
        local i=0
        
        for item in "${items[@]}"; do
            i=$((i + 1))
            local is_last=$([ $i -eq $count ] && echo "true" || echo "false")
            local item_path="$dir/$item"
            
            # 当前层级的符号
            if [ $depth -eq 0 ]; then
                local line_prefix=""
            else
                if [ "$is_last" = "true" ]; then
                    local line_prefix="${prefix}└── "
                else
                    local line_prefix="${prefix}├── "
                fi
            fi
            
            # 如果是目录
            if [ -d "$item_path" ]; then
                echo "${line_prefix}${item}/"
                if [ "$is_last" = "true" ]; then
                    local new_prefix="${prefix}    "
                else
                    local new_prefix="${prefix}│   "
                fi
                generate_structure "$item_path" "$new_prefix" $((depth + 1))
            else
                # 文件
                echo "${line_prefix}${item}"
            fi
        done
    }
    
    # 生成并保存
    {
        echo "$(basename "$(pwd)")/"
        generate_structure "." "" 1
    } > "$OUTPUT_FILE"
    
    echo "✅ 结构图已生成: $OUTPUT_FILE"
fi

# 显示文件信息
echo ""
echo "📊 文件信息:"
wc -l "$OUTPUT_FILE"
echo "---"
head -20 "$OUTPUT_FILE"
```

## 项目结构最佳实践

### 1. 目录命名规范
- 使用小写字母和连字符：`src/components/user-profile/`
- 避免空格和特殊字符
- 保持名称简洁明了

### 2. 文件组织原则
- **按功能组织**：将相关文件放在一起
- **按类型组织**：组件、工具、样式等分类存放
- **按层级组织**：从通用到具体

### 3. 常见目录说明
- `src/` - 源代码
- `tests/` - 测试文件
- `docs/` - 文档
- `scripts/` - 脚本文件
- `config/` - 配置文件
- `public/` - 静态资源
- `dist/` - 构建输出
- `node_modules/` - Node.js依赖（不应提交到版本控制）

### 4. 版本控制忽略
确保在 `.gitignore` 中包含：
```
# 依赖目录
node_modules/
venv/
__pycache__/

# 构建输出
dist/
build/
*.exe
*.dll

# 环境文件
.env
.env.local

# 编辑器文件
.vscode/
.idea/
*.swp
```

### 5. 文档结构
```
docs/
├── README.md          # 文档首页
├── getting-started/   # 入门指南
├── api-reference/     # API文档
├── guides/            # 使用指南
├── examples/          # 示例代码
├── faq/               # 常见问题
└── CHANGELOG.md       # 更新日志
```

## 使用建议

1. **保持一致性**：在整个项目中保持相同的目录结构
2. **适度分层**：避免过深的目录嵌套（通常不超过4层）
3. **明确命名**：目录和文件名称应清晰表达其内容
4. **定期整理**：随着项目发展，适时调整目录结构
5. **团队共识**：确保团队成员都理解并遵循项目结构规范
