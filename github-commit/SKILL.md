# GitHub提交管理技能

## 概述

此技能提供完整的GitHub仓库提交工作流程，包括仓库状态检查、远程链接验证、代码审核和提交创建。确保代码正确提交到指定的GitHub仓库。

## 工作流程

### 1. 检查当前仓库状态
首先检查当前目录是否是Git仓库，以及是否已配置远程仓库链接。

**触发条件**：当用户需要提交代码但不确定当前仓库状态时。

**操作步骤**：
1. 运行 `scripts/check_git_status.py` 检查仓库状态
2. 显示远程仓库链接、当前分支和未提交的更改
3. 确认是否使用现有的远程仓库链接

**示例用户请求**：
- "检查当前仓库状态"
- "查看Git仓库的远程链接"
- "确认当前分支和更改状态"

### 2. 验证或更新远程仓库链接
如果远程仓库链接不存在或需要更新，允许用户验证或更新GitHub仓库链接。

**触发条件**：
- 当前仓库没有配置远程链接
- 用户需要更改远程仓库链接
- 远程链接无效或需要验证

**操作步骤**：
1. 使用 `scripts/update_remote.py` 验证GitHub URL格式
2. 如果远程已存在，提示用户确认是否更新
3. 添加或更新远程仓库链接
4. 测试远程连接

**示例用户请求**：
- "更新远程仓库链接到 https://github.com/username/repo.git"
- "添加GitHub远程仓库"
- "验证当前远程链接是否正确"

### 3. 审核代码并创建提交
审核代码更改，生成合适的提交消息，并创建提交。

**触发条件**：当用户需要提交代码更改时。

**操作步骤**：
1. 使用 `scripts/create_commit.py` 检查代码更改
2. 根据更改类型生成提交消息建议
3. 验证提交消息格式
4. 添加更改到暂存区并创建提交
5. 可选：推送到远程仓库

**示例用户请求**：
- "提交当前更改"
- "创建提交并推送到GitHub"
- "审核代码并生成提交"

## 脚本使用说明

### check_git_status.py
检查Git仓库状态的脚本。

**用法**：
```bash
python scripts/check_git_status.py [目录路径]
```

**输出**：
- 仓库状态（是否是Git仓库）
- 远程仓库链接
- 当前分支
- 未提交的更改列表
- 最近提交历史

### update_remote.py
更新Git远程仓库链接的脚本。

**用法**：
```bash
python scripts/update_remote.py <目录> <远程名称> <GitHub URL>
```

**示例**：
```bash
python scripts/update_remote.py . origin https://github.com/username/repo.git
```

**功能**：
- 验证GitHub URL格式
- 添加或更新远程仓库
- 测试远程连接

### create_commit.py
创建Git提交的脚本。

**用法**：
```bash
python scripts/create_commit.py <目录> <提交消息> [--push]
```

**示例**：
```bash
# 仅创建提交
python scripts/create_commit.py . "修复登录页面样式问题"

# 创建提交并推送
python scripts/create_commit.py . "添加新功能模块" --push
```

**功能**：
- 验证提交消息格式
- 自动生成提交消息建议
- 添加所有更改到暂存区
- 创建提交
- 可选推送到远程仓库

## 最佳实践

### 提交消息规范
- 使用中文或英文描述更改内容
- 消息长度：10-200字符
- 清晰描述更改的目的
- 避免使用模糊的词语如"更新"、"修复"

### 远程链接验证
- 确保GitHub URL格式正确
- 测试远程连接是否正常
- 确认有访问权限

### 代码审核
- 检查更改的文件列表
- 确认没有意外更改
- 确保不提交敏感信息（如API密钥、密码）

## 错误处理

### 常见错误及解决方案
1. **不是Git仓库**：在当前目录初始化Git仓库
2. **远程链接无效**：检查URL格式和网络连接
3. **提交消息太短**：提供更详细的描述
4. **没有更改可提交**：确认有未提交的更改
5. **推送权限不足**：检查GitHub访问权限

### 安全注意事项
- 不自动提交包含敏感信息的文件
- 提示用户确认远程仓库链接
- 不自动强制推送更改

## 技术实现细节

### 脚本功能说明

#### 1. check_git_status.py
- **输入**: 可选目录路径（默认当前目录）
- **输出**: JSON格式的仓库状态信息
- **功能**:
  - 验证是否是Git仓库
  - 获取远程仓库信息
  - 显示当前分支状态
  - 列出未提交的更改
  - 显示最近提交历史

#### 2. update_remote.py
- **输入**: 目录路径、远程名称、GitHub URL
- **输出**: 操作结果状态
- **功能**:
  - 验证GitHub URL格式（支持HTTPS和SSH）
  - 检查现有远程配置
  - 交互式确认更新操作
  - 测试远程连接可用性
  - 提供详细的错误信息

#### 3. create_commit.py
- **输入**: 目录路径、提交消息、可选推送标志
- **输出**: 提交操作结果
- **功能**:
  - 验证提交消息格式和长度
  - 自动分析更改类型生成建议消息
  - 批量添加所有更改到暂存区
  - 创建提交并可选推送到远程
  - 提供详细的进度反馈

### 错误处理机制

所有脚本都包含完善的错误处理：
1. **输入验证**: 检查参数有效性
2. **Git操作验证**: 确认Git命令执行成功
3. **网络连接测试**: 验证远程仓库可达性
4. **用户确认**: 重要操作前请求用户确认
5. **详细错误信息**: 提供可操作的错误提示

### 安全特性

1. **权限检查**: 不自动执行高风险操作
2. **敏感信息保护**: 提示用户检查提交内容
3. **确认机制**: 重要更改需要用户确认
4. **撤销支持**: 提供操作撤销指导
